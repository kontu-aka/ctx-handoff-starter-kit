# サンプル — 架空の焼き菓子店「くるみ堂」

実物を見るのが一番早いので、記入済みの例と、**実際に3つのAIへ渡した結果**、
および**利用者から提供された実測**を収録しています。
**このサンプルは架空の案件です。** 実在の店舗・人物とは関係ありません。

---

## ① BEFORE — 引き継ぐ前の状態

長い会話の中に、こういうものが混ざっています。

- 「トップの構成はこれでいきましょう」 ← **決定**
- 「写真は後で差し替えます」 ← **保留**
- 「予約機能は初期版では入れません」 ← **却下**
- 「次は商品一覧ですね」 ← **次にやること**

新しいチャットや別のAIへ移った瞬間、この4種類はすべて過去ログになります。
CTXでは、再開に必要な状態だけを取り出して1枚にまとめます。

## ② CTX — 記入済みの実物

```markdown
# CTX Handoff

## 目的
架空の焼き菓子店「くるみ堂」のWebサイト初期版を作る。

## 現在地
トップページの構成が確定。商品一覧ページは未着手。

## 決定
- [決定] 商品データは構造化して管理する（後から追加しやすくするため）

- [保留 / ブロック: いいえ] 商品写真 — 撮影待ち。仮画像で進行可
- [保留 / ブロック: はい] 最終コピー文 — 店主確認待ち。文言確定まで公開不可

## 却下
- [却下] オンライン予約機能 — 初期版では入れない（運用体制が未整備のため）

## 作成・変更ファイル
- `index.html`（作成済み / トップページ）
- `style.css`（作成済み）

- 商品データは `products.json` に集約する。HTMLへ直接書かない。
- 実在の店舗情報・住所・電話番号は入れない（本案件は架空）。

事実 / 決定 / 提案 / 未確認 / 却下

- 価格、開店日、住所、電話番号、店主名 — **一切未提示**。推測して書かないこと。

## 検索用キーワード
くるみ堂 / 焼き菓子 / 商品一覧 / products.json / 初期版
```

## ④ 実測 — 3つのAIに同じCTXを渡した結果

実施日：2026-08-16 / 使用AI：ChatGPT・Claude・Gemini

| 確認項目 | ChatGPT | Claude | Gemini |
|---|:---:|:---:|:---:|
| 復唱してから作業を始めたか | ✕ | ○ | ○ |
| 決定事項を維持したか | ○ | ○ | ○ |
| 却下案（予約・会員登録）を復活させなかったか | ○ | ○ | ○ |
| 未提示情報を捏造しなかったか | ○ | ○ | △ |
| 指示された次作業を実行したか | ○ | ○ | ○ |

**3つとも、決定事項の維持と却下案の非復活は達成しました。**
一方で、復唱の実行と未確定値の扱いには差が出ています。

### ChatGPT

- 作業内容は正確
- ただし、復唱を行わずに作業へ入った
- 未確定価格は `null` とし、未確認である理由も明記した

### Claude

- 6項目を復唱
- CTX上で「作成済み」とされた `index.html` / `style.css` が、新しいセッションには実ファイルとして存在しないことも指摘
- 未確定価格は注記フィールドで区別した

### Gemini

- 復唱を実行
- 決定・却下も維持
- ただし未確定価格に `"price": 0` を使用したため、「未確定」と「無料」を区別できず △
- CTXにない `isFeatured` フィールドも追加した

## ⑥ 実測（利用者提供）—— 複数の話題が混在したチャットで試した場合

報告者：Can さん / 使用AI：ChatGPT / 使用元：GitHub版
※ ご本人の許可を得て収録しています。

### 今回観測されたこと

- 既存チャットの末尾にCTXテンプレートを貼り、CTX生成を依頼した
- そのチャット内には雑談や複数の案件が混在していた
- **意図していた案件とは別の案件のCTXが生成された**

### 報告者の観察（要旨）

Can さんからは、完全にランダムに別案件を拾ったというより、
混在していた話題の中で会話量の多い案件を対象として拾ったように見えた、という観察がありました。

また、「混在チャットでは壊れる」と断定するより、
対象を明示しない場合にAI側が主題を推定する挙動なのかもしれない、という留保付きの見方も示されています。

### この実測から分かること

この1件では、対象候補が複数ある状態で対象を明示せずCTX生成を依頼したところ、
**AIが確認を挟まずに、意図とは別の案件のCTXを生成しました。**

この実測は1件の報告です。一般的な性質として確認されたものではありません。

### 未検証（今回は分からないこと）

- AIがどのような内部基準で対象を選んだか
- 会話量を基準にしたか
- チャットタイトルをどの程度参照したか
- 他のAI・他の条件でも同じ挙動になるか

### 対処方法

AIにCTXを作らせるときは、次の2行を基本形として使います。

```
CTXを作成してください。
対象候補が複数ある場合は、CTXを作る前にどれを対象にするか確認してください。
```

対象が明らかに1件だけの場合は、「CTXを作成してください」だけでも使えます。

最初から対象が決まっている場合は、任意で明示しても構いません。

```
このチャット内の「○○の案件」だけを対象にCTXを作成してください。
他の話題は対象外としてください。
```

いずれの場合も、生成されたCTXの「目的」が意図した案件になっているかを、
渡す前に一度確認してください。
