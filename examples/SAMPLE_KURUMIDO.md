# サンプル — 架空の焼き菓子店「くるみ堂」

実物を見るのが一番早いので、記入済みの例と、**実際に3つのAIへ渡した結果**を収録しています。
**このサンプルは架空の案件です。** 実在の店舗・人物とは関係ありません。

---

## ① BEFORE — 引き継ぐ前の状態

長い会話の中に、こういうものが混ざっています。

- 「トップの構成はこれでいきましょう」 ← **決定**
- 「写真は後で差し替えます」 ← **保留**
- 「予約機能は初期版では入れません」 ← **却下**
- 「次は商品一覧ですね」 ← **次にやること**

新しいチャットや別のAIへ移った瞬間、この4種類はすべて過去ログになります。
CTXでは、再開に必要な状態だけを取り出して1枚にまとめます。

---

## ② CTX — 記入済みの実物

```markdown
# CTX Handoff

## 目的
架空の焼き菓子店「くるみ堂」のWebサイト初期版を作る。

## 現在地
トップページの構成が確定。商品一覧ページは未着手。

## 決定
- [決定] 商品データは構造化して管理する（後から追加しやすくするため）
- [決定] トップページ構成：ヒーロー → 商品紹介3点 → 店舗情報 → 問い合わせ
- [決定] 初期版はスマートフォン表示を優先する

## 保留
- [保留 / ブロック: いいえ] 商品写真 — 撮影待ち。仮画像で進行可
- [保留 / ブロック: はい] 最終コピー文 — 店主確認待ち。文言確定まで公開不可

## 却下
- [却下] オンライン予約機能 — 初期版では入れない（運用体制が未整備のため）
- [却下] 会員登録機能 — 同上

## 作成・変更ファイル
- `index.html`（作成済み / トップページ）
- `style.css`（作成済み）
- `products.json`（未作成 / 次工程で作る）

## 保存上の注意
- 商品データは `products.json` に集約する。HTMLへ直接書かない。
- 実在の店舗情報・住所・電話番号は入れない（本案件は架空）。

## 次にやること
1. `products.json` の項目設計（商品名 / 説明 / 価格 / 画像パス / 表示順）
2. 商品一覧ページの作成
3. トップの商品紹介3点を `products.json` から読む形へ差し替え

## 情報状態の凡例
事実 / 決定 / 提案 / 未確認 / 却下

## 未確認事項（AIが埋めてはいけないもの）
- 価格、開店日、住所、電話番号、店主名 — **一切未提示**。推測して書かないこと。

## 検索用キーワード
くるみ堂 / 焼き菓子 / 商品一覧 / products.json / 初期版
```

## ③ 渡し方

## ④ 実測 — 3つのAIに同じCTXを渡した結果

実施日：2026-08-16 / 使用AI：ChatGPT・Claude・Gemini

| 確認項目 | ChatGPT | Claude | Gemini |
|---|:---:|:---:|:---:|
| 復唱してから作業を始めたか | ✕ | ○ | ○ |
| 決定事項を維持したか | ○ | ○ | ○ |
| 却下案（予約・会員登録）を復活させなかったか | ○ | ○ | ○ |
| 未提示情報を捏造しなかったか | ○ | ○ | △ |
| 指示された次作業を実行したか | ○ | ○ | ○ |

**3つとも、決定事項の維持と却下案の非復活は達成しました。**
一方で、復唱の実行と未確定値の扱いには差が出ています。

### ChatGPT

- 作業内容は正確
- ただし、復唱を行わずに作業へ入った
- 未確定価格は `null` とし、未確認である理由も明記した

### Claude

- 6項目を復唱
- CTX上で「作成済み」とされた `index.html` / `style.css` が、新しいセッションには実ファイルとして存在しないことも指摘
- 未確定価格は注記フィールドで区別した

### Gemini

- 復唱を実行
- 決定・却下も維持
- ただし未確定価格に `"price": 0` を使用したため、「未確定」と「無料」を区別できず △
- CTXにない `isFeatured` フィールドも追加した

## ⑤ この実測から言えること

### 言えること

- 同じ1枚のCTXを3つのAIに渡し、3つとも決定事項を維持した
- 3つとも却下済みの予約・会員登録を復活させなかった
- 3つとも指定された次作業から着手した
- 特定AI専用に書き分けなくても、同じCTXを使えた

### 言えないこと

- すべてのAI・すべての状況で同じ結果になるとは言えない
- これは 2026-08-16 時点・このダミー案件・この試験条件での結果
- 復唱や未確定値の扱いには実際に差が出た

## ⑥ AFTER — 変わること

| | 引き継ぎ前 | CTXあり |
|---|---|---|
| 再開時の説明 | 経緯を最初から説明し直す | CTXを貼って再開 |
| 決定事項 | 会話に埋もれる | 一覧で残る |

| 未確定情報 | 推測で埋められることがある | 「未提示」と明示される |
| 別のAIへ渡す | 会話ごと持ち出しにくい | 同じ1枚を渡せる |
